# -calculadora-_numpy
Mini projeto para treinar POO e numpy, utilizando as ferramentas para criar uma "calculadora" de matrizes e vetores. Até no momento atual realizei algumas classes e métodos que tem como objetivo transpor matrizes enviadas pelo usuário onde o usuário tem a liberdade de escolher o número de linhas e colunas de sua matriz e logo em seguida transpô-la
